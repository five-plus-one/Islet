# Islet 工作台验收记录

日期：2026-10-08。产品设计见 [product-design.md](product-design.md)。

## 交付范围

工作台采用统一的蓝色与浅色视觉体系，提供桌面侧栏、手机导航、图片卡片、详情抽屉、独立上传队列和一致的表单反馈。图库支持组合筛选、链接格式、批量操作与相册管理；本地账户可修改密码，超级管理员可创建本地用户。管理页面覆盖存储、分组、用户、设置和运行概览。

后端补齐管理权限、用户归属、上传密钥权限、配额核算、回收生命周期、稳定分页与存储保护；图片读取支持本地文件与对象存储代理。

### 七组业务验收

1. 身份与授权：本地登录、未登录访问、管理员边界、跨来源写入、分组编辑、创建本地账户、用户图片与相册隔离。
2. 图片生命周期：编辑标签、搜索、时间与 ID 游标分页、重复上传、原图与缩略图读取、回收、恢复、永久删除和相册引用检查。
3. 上传凭据与账户：PicGo 上传、密钥权限、撤销失效、错误文件、超配额、停用账户、修改密码与会话撤销。
4. 桌面交互：登录、创建相册、批量上传、缩略图加载、详情编辑和取消、搜索、管理页面导航及浏览器运行错误检查。
5. 响应式与恢复：390px 手机、768px 平板下的图库和各管理页面布局、手机导航、503 加载失败与重试。另验收 1440px 桌面布局。
6. 对象存储：真实 S3 兼容策略上传、代理读取与缩略图、策略使用权限、引用中策略约束、停用后读取、删除失败保留记录及修复后重试。
7. 上传与批量操作：失败重试、跨页面队列保留、实际剪贴板内容、批量回收与恢复、过期会话返回登录。

桌面图库、手机图库、手机上传、详情与登录页截图保存在 `workspace/screenshots/`，已人工查看主要布局。测试入口为 `frontend/admin/e2e/acceptance.spec.ts`；准备容器使用 `scripts/start-acceptance.ps1`，更新验收镜像使用 `scripts/update-acceptance.ps1`。

## 验证边界

本轮以本地账户为认证方式，完成本地磁盘与 MinIO 的真实业务验收。外部 OIDC 提供方、阿里云 OSS、其他 S3 服务、公网 HTTPS/反向代理、备份恢复及持续高负载需要在实际部署环境专项验证。测试通过表示上述场景已验证，不能替代所有生产环境和并发规模的验证。
