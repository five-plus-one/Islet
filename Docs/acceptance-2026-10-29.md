## 运维与恢复

生产目录 `/opt/islet-production`，数据位于 `data/`，Compose 为 root 专用 `compose.json`。初始迁移备份位于 `backups/20261029`；每日备份位于 `backups/daily`，由 `islet-backup.timer` 调度，包含数据库、运行配置、加密主密钥与恢复凭据。

本地恢复账户为 `islet-admin`。凭据保存在应用机 root 专用 `credentials.json`，本机副本为当前 Windows 用户 DPAPI 加密的 `workspace/production-recovery.key`，不进入 Git。

网关原配置位于 `/opt/1panel/www/sites/img-5plus1/root.before-islet-20261029.conf`。回滚入口前先评估切换后新增图片与账户变更，再启动旧容器、恢复该站点代理并执行 nginx 配置检查及 reload。数据库恢复必须同时保留 `islet.key`，不能以旧数据库覆盖新上传。

## 验收边界

本次验证覆盖上述功能与布局，不代表所有设备、并发压力和未来依赖变化都已验证。npm 审计报告 6 项低等级依赖链提示，源于共享库数学渲染依赖 KaTeX 的原型污染前置条件问题；图床不提供数学渲染入口。无中、高或严重等级提示。应用机根分区约 5.1 GiB 可用，既有低于 10% 容量告警继续由服务器运维跟踪。

自动化入口：frontend/admin 下 npm run test:e2e 执行 4 组 API 验收；浏览器交互通过实际 Chrome 会话验收。开发代理默认 18091 / 18090，独立验收环境可用 ISLET_ADMIN_URL、ISLET_PUBLIC_URL 指定 28091 / 28090。
