# 管理端编辑验收

日期：2026-11-01。关联 Issue：[#1](https://github.com/five-plus-one/Islet/issues/1)、[#2](https://github.com/five-plus-one/Islet/issues/2)。

## 已验证行为

| 范围 | 结果 |
| --- | --- |
| 默认分组编辑 | 正式站点复现历史空存储列表异常；候选支持直接打开编辑、刷新、保存与重新读取 |
| 分组限制 | 新建指定本地存储的分组，容量与单张上限为 0、格式留空，保存刷新后指定存储仍保留；空指定范围阻止保存 |
| 输入与失败 | 负数、无效 CDN 域名、重复名称有错误反馈；保存失败保留草稿；分区切换保留输入 |
| 草稿保护 | 取消和侧栏导航显示放弃提示，继续编辑恢复当前草稿，放弃后进入目标页面 |
| 存储配置 | 本地存储创建后回读；对象存储更名保存时密钥留空，随后真实连接测试成功 |
| 布局与键盘 | 390、600、900 和默认 1384 像素窗口；深浅主题；分区方向键、Esc 关闭与焦点路径；窄屏无页面横向溢出，保存取消可达 |
| 弹层审查 | 用户创建 3 字段、相册 2 字段、密钥 2 字段、移动图片 1 字段；图片详情采用全高侧栏，审核确认与 PicList 宽布局可操作 |
| 异常路径 | 不存在的分组提供返回列表；发布候选浏览器没有脚本错误 |

写入验收使用本机隔离应用与数据库，以及独立 S3 测试存储。正式数据不用于写入测试。页面使用已发布的共享表单组件，宿主仅适配内容宽度、滚动容器与业务逻辑。

## 发布恢复

候选镜像：`islet:production-20261101.04`。恢复镜像：`islet:production-20261101.03`。本次保持数据库结构兼容；发布只切换 Islet 服务。上线前保存原配置及备份，比较账户、图片、分组、存储配置、环境、挂载、网络和其他业务容器，切换后回读正式编辑入口。
