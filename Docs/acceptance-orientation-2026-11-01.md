# 照片方向验收

## 浏览器页面验收

正式站通过 Chrome 浏览器专用工具完成相册封面、图片列表和三张实际照片的详情验收。媒体预览以固定容器约束图片，按原始比例居中完整显示横图和竖图；封面、列表和上传结果采用同一显示规则。

390、600、900 和 1384 像素窗口、深浅色、相册进入与返回、刷新按钮和整页刷新、Esc 关闭详情通过。八张相册图片全部从 CDN 加载，三张竖图缩略图为 320 × 480，详情为 2784 × 4176；图片实际边界与预览容器相符。窄屏“更多操作”菜单完整显示并可键盘关闭，放宽窗口后常用操作恢复展开。页面控制台错误为 0。

隔离环境完成竖图实际上传、结果缩略图、原地预览与键盘关闭；共享组件 4 项测试、前端类型检查与生产构建通过。共享媒体组件为 `0.5.77-media.3`，随包提供 MIT 源码；[公网组件示例](https://ui.five-plus-one.com/media/)版本回读及 238 个静态资源 SHA-256 校验通过。

正式版本：`production-20261101.03`。页面提交：[f65d856](https://github.com/five-plus-one/Islet/commit/f65d856a9ff88b427e358dde3869a0c4c7ad03c5)，[CI 通过](https://github.com/five-plus-one/Islet/actions/runs/41279007223)。方向处理提交：[d0f88ec](https://github.com/five-plus-one/Islet/commit/d0f88ec9face9fde15ff44e386a3cd330b68289d)。

缩略图按照片 EXIF 方向处理旋转与镜像，上传宽高对应显示尺寸；原图保持原始字节。支持 JPEG APP1、PNG eXIf 与 WebP EXIF，异常元数据回退正常方向，解码前执行大小与像素限制。

八种方向分别验证四角位置与显示尺寸，覆盖两种字节序；PNG 端到端缩略图、WebP 容器、截断和无效元数据通过。方向解析随机输入测试执行约 50 万次，通过。Go 构建和全包测试通过；隔离 MySQL 测试验证预检、修复、重复执行、正确缩略图保持、缓存任务持久失败回滚以及保留原图、旧缩略图和审核状态。

正式环境预检 46 张图片，3 张需要重建缩略图。仅应用于预检确认的图片编号，新的显示尺寸为 2784 × 4176；重复预检显示无需再次修复。源站返回新缩略图字节与新 ETag，3 个持久 CDN 刷新任务全部完成。已回读修复后的实际封面确认竖向显示。

仅更新 Islet 服务，其他 20 个应用机容器、账户、站点与运行配置保持。原图记录及相册、标签、审核状态、上传时间保持。原缩略图保留，恢复材料与私有维护记录共同保存。

页面版本发布前后再次比对全部 46 条图片记录、账户、配置及其他 20 个容器，通过；健康检查与发布前后备份成功。共享组件示例通过独立媒体入口发布，其他站点入口及网关容器保持。
