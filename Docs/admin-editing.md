# 管理端编辑流程

关联问题：[#1](https://github.com/five-plus-one/Islet/issues/1)、[#2](https://github.com/five-plus-one/Islet/issues/2)。

## 页面与表单

用户分组和存储策略使用独立编辑页，支持直接访问与刷新。列表保留管理入口；编辑页明确显示对象名称、返回入口和保存、取消操作。

- 分组：基本信息、容量与上传、可用存储三个分区。
- 存储策略：基本信息、存储连接、图片访问三个分区。本地存储只显示适用选项。
- 复用已发布共享库的 ManagementForm、WorkspaceSection、表单网格、Checkbox、Button 等组件。业务页面处理权限、验证、请求、草稿和保存。
- 分区切换保留草稿。保存时验证全部分区，错误时定位对应分区并保留输入。
- 编辑期间离开页面提示保存状态，可继续编辑或放弃修改。保存中防止重复提交和导航。
- 编辑既有存储时密钥留空表示保留，页面不回显密钥，不在浏览器持久保存草稿。
- 名称重复时显示可理解的重名提示，保存失败保留草稿；服务端分组错误不向页面返回数据库诊断。

## 兼容与含义

历史分组的空存储列表与空格式列表可能返回 null。前端请求边界将 null 归一化为空数组，保留有效限制项。空存储列表代表全部存储，空格式列表代表全部受支持图片格式；界面明确解释这一含义，选择指定存储时必须至少选择一项。容量、单张上限和每小时上传数量为 0 时表示不限，不能显示为 0 B。数值保存前验证非负、有限且字节数和数量为安全整数。

## 弹层使用

仅保留删除确认、创建本地用户、创建相册、上传密钥、移动图片等短任务弹窗。图片详情保留带预览的侧栏；客户端连接使用现有宽布局。逐项检查内容量、焦点、关闭行为和操作位置，避免页面与浮层同时出现无意义的多层滚动。

## 验收

1. 默认分组与自定义分组均可打开、刷新、编辑、保存并重新读取；历史 null 数组不导致异常。
2. 分组限制、存储选择与已有密钥保持正确含义；取消、切换分区和失败重试保留预期草稿。
3. 本地与对象存储完整配置均能编辑，加载失败和目标不存在可恢复。
4. 桌面、分屏、手机连续缩放，深浅色与键盘操作可用；保存取消可达，弹层和提示不遮挡内容。
5. 正式站点仅执行读取、打开与取消；写入测试在隔离验收环境进行。
6. 验收完成后创建 PR，发布版本关联测试结果、线上检查与恢复版本。
