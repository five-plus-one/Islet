# 图片审核

管理员与超级管理员可在“图片审核”中查看全站有效图片，按上传者、关键词与访问状态筛选。个人图片库保持本人范围，上传者可查看访问限制和原因；普通用户不能修改审核结果。

## 操作与状态

- 正常：公开链接返回图片。
- 禁止访问：管理员填写最多 500 字的原因并确认，原图与缩略图的公开入口返回固定的“图片违反使用策略”提示图片。原文件、名称、标签、相册和存储占用保留。
- 恢复访问：管理员确认后，同一链接重新返回原图；记录操作者与操作时间。
- 受限图片的原图仅通过需要管理员交互会话的预览入口读取，用于复核，返回私有且禁止存储的响应。
- 回收站恢复不解除访问限制，同用户重复上传命中原记录时也保留限制。

批量操作逐项报告结果，部分失败后保留可重试状态。操作按钮复用共享 ActionToolbar、Button、Dialog、Field、ResourceExplorer 和即时提示。

## 数据与权限

在 images 增加 blocked（默认 false）、block_reason、moderated_by、moderated_at。已有图片保持正常。审核变更与 audit_logs 写入同一事务；原因仅在账户界面可见，公开提示图片不暴露原因、账户信息或文件信息。

新增 PATCH /api/admin/images/:id/moderation，输入 blocked 与 reason；GET /api/admin/images/:id/preview 供管理员读取原图，thumb=1 获取缩略图。列表支持 moderation=active|blocked；管理员全站视角支持 user_id。使用现有组合游标分页。

## 访问与兼容

图片链接默认使用存储策略配置的 CDN 域名，保留 `/i/`、`/t/` 受控路径；没有配置加速时使用站点地址。普通图片允许节点缓存 30 天，浏览器每次校验（`public, max-age=0, s-maxage=2592000, must-revalidate`）。受限、未找到及管理员复核响应禁止缓存。先检查审核状态再处理条件请求；ETag 包含最近审核时间。受限时 GET 与 HEAD 返回 image/svg+xml 提示图。

新上传与工作台分享链接统一使用 /i/ 和 /t/ 受控入口，由已启用缓存同步的 CDN 分发。对象存储读取由应用代理。外部已发布的对象存储直链、CDN 缓存和浏览器中已保存的内容需要独立处理；上线前核查实际存储与旧域名链路，不能以应用入口校验代替旧链路验收。

`/legacy/{key}` 兼容已发布的原文件与缩略图路径，仅查找已有且未回收记录，同样检查限制状态。CDN 回源到该受控入口，源对象使用私有读取。已下载的副本无法远程收回。

## CDN 同步

审核、回收、恢复和彻底删除与缓存刷新任务写入同一数据库事务。任务保存原图、缩略图的现行及历史 CDN URL 快照；删除图片不删除任务。后台每 15 秒处理到期任务，阿里云刷新提交后查询全网完成状态，失败指数退避重试；任务持久化，服务重启后继续。提交超时允许重复刷新，操作幂等。仅全网任务完成后显示“访问状态已同步”，处理中显示“正在同步访问状态”；失败说明将自动重试。阿里云全网刷新通常约 5–6 分钟，在此期间部分节点仍可能返回之前的图片。

每个 CDN 策略配置加速域名与阿里云刷新开关，使用该策略已有密文凭据。RAM 仅需该域名的 `cdn:RefreshObjectCaches` 和 `cdn:DescribeRefreshTasks`。未配置刷新能力的策略不启用节点缓存。管理预览、上传 API 和账号接口不使用图片 CDN 地址。节点缓存按无查询参数的路径合并，以覆盖带参数的历史链接。

新增 `cdn_cache_jobs`：图片与策略编号、URL 快照、提交后的任务编号与提交时间、状态、尝试次数、下次处理时间、错误代码、创建与更新时间。领取使用事务锁与租约，防止多实例重复并发处理；租约到期后可恢复。完成记录保留用于操作追踪。

## 验收

覆盖管理员跨账户查询与复核、普通用户越权拒绝、原因校验、封禁与恢复、原文件字节一致、缩略图与 HEAD、条件请求、重复上传、回收站恢复、审核失败事务回滚、筛选和分页。页面检查宽窄容器、深浅色、键盘焦点、确认反馈与错误重试。
