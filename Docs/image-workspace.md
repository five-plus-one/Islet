# 图片工作台

## 上传与取链

上传页按保存位置、添加图片、使用上传结果的顺序组织。相册与存储位置在添加图片前可见，标签放在可展开的选项中。选择、拖入和粘贴均立即加入队列；上传继续运行，直到完成、取消或退出账户。

结果区展示图片预览、文件名、大小和上传状态。每张已完成图片提供可选择的链接与复制按钮；链接格式作用于所有结果，并支持复制全部已完成链接。清除已完成只移除本次列表，不删除图片。失败项说明原因，支持重试或移出列表；不支持的格式和超限文件不能重试。

## 相册浏览

相册以有边界的封面卡片呈现，卡片主区域打开相册，菜单提供重命名与删除。空相册保留清晰的空封面。封面采用相册中最近添加的有效图片，遵循图片访问策略，回收站图片不参与封面与计数。

相册列表返回 `cover_url`，通过现有图片记录计算，不新增数据库字段。仅查询当前账户相册和图片。进入相册后显示相册名称、返回相册列表与上传到当前相册的入口。

图片库与相册采用相同的图片网格。单击图片打开详情，独立复选框用于批量选择，逐张复制按钮始终可见。网格呈现真实缩略图、文件名、大小与必要的访问状态；高级筛选可展开，搜索和主要范围选择保留在前。页面自然滚动，不在图库内部嵌套文件列表滚动区域。

操作栏按实际宽度展开按钮，隐藏的测量行不影响页面滚动宽度。「更多」菜单只呈现一次操作名称，图标与可见文字保持同一语义。

## 连接 PicList

连接面板先填写密钥和保存位置，再按 PicList「高级自定义」的字段顺序显示配置值。固定协议项以紧凑的只读配置行展示，复制按钮紧邻值。请求头显示遮罩，复制时使用实际密钥；密钥不写入浏览器存储。面板的完成操作始终可达。配置片段供 PicList Core 使用，不标示为桌面客户端的一键导入。

## 共享组件与验收

图片上传、结果列表、封面卡片与配置行维护在 5plus1-ui 的独立媒体工作台入口，业务项目提供数据和操作。发布在 0.5.77 的兼容扩展版本中，随包分发 MIT 组件源码。

验收覆盖多图上传、粘贴、失败重试、逐张和批量复制、格式切换、页面切换后继续上传、创建及进入相册、相册内上传、PicList 实际上传，以及深浅色、键盘、手机、分屏和连续缩放。上传状态使用「上传成功」，以服务返回的图片记录作为完成依据。
