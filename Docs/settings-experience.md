# 系统设置与公开发行

设置按站点、登录、上传与成员三个任务组织，每次只展示一个分区，复用共享组件库的导航、表单、按钮和卡片。字段旁说明实际用途、可选项与边界；回收站设为 0 表示保留至手动清空。

管理接口单独返回登录配置的部署默认值与回调地址，不返回客户端密钥。页面区分已保存覆盖值与部署默认值；保存仅提交变更字段，清空覆盖值后恢复部署默认值。登录服务检查使用当前表单的有效地址，并说明检查只验证服务发现。

保存前保留输入，提供未保存提示、撤销与独立错误反馈。切换分区保留草稿。浏览器离开时提示未保存内容。关闭本地登录仍受后端至少一种登录方式的校验保护。

公开发行包含安装文档、贡献与安全报告流程、许可证和产品中的 GitHub 入口。公开前审查历史、依赖授权与部署资料；生产凭据及专用运维资料不属于公共发行内容。
