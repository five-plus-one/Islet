# 管理图床设置

在工作台选择「系统设置」，按任务切换三个分区。修改后点击「保存更改」；切换分区保留草稿，「撤销更改」恢复本次加载或最近保存的内容。

## 站点信息

站点名称显示在浏览器标题与侧栏。品牌名称、品牌图标和统一登录按钮名称用于登录页。

图片访问地址应填写图床对外提供服务的完整 HTTP(S) 地址。若存储策略使用独立 CDN 域名，应在对应存储策略中设置访问地址。修改地址前确认新域名已经正确反向代理；已有外部链接不会自动迁移。

## 登录方式

页面显示当前有效的统一登录地址。字段为空并且下方显示「留空使用部署配置」时，系统正在使用服务器配置的值。输入内容会覆盖该值，清空并保存会恢复使用部署配置。

在身份提供方创建 OIDC 应用后，将其 Issuer 与 Client ID 填入对应字段，并登记页面展示的回调地址。Audience 仅在提供方要求时设置；Scopes 默认是 openid profile email。需要客户端密钥的应用仍由服务器环境变量 OIDC_CLIENT_SECRET 提供，管理页面不读取或展示密钥。

「检查登录服务」验证服务发现地址可访问；完整登录还需验证应用授权与回调。关闭本地登录前，应实际完成一次统一登录，保留受控的管理员恢复方式。

## 使用规则

单张图片上限允许 1–100 MB，用户分组的更严格限制仍然生效。回收站保留时间允许 0–3650 天，0 表示仅手动清空；自动清理在后台定期执行，到期文件清理后无法恢复。

关闭自动通过新用户注册后，新加入的统一登录用户需要管理员审核；已经加入的成员不受影响。
