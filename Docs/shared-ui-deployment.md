# 共享工作台与公网部署

## 实施方案

2026-10-29 确认将管理端迁移至 React 19，直接消费 `@fiveplusone/ui` 已发布的 0.5.75 组件。复用现有 Go API、图片地址、账户与配额模型；业务项目负责路由、授权、请求和上传状态。

工作台使用共享按钮、字段、对话框、导航、资源浏览器、上传队列、主题切换、即时提示及按容器宽度折叠的 ActionToolbar。深浅色均采用 `--fp-*` 语义变量，品牌主题为五加一橙。菜单、详情与表单使用共享弹层，保留键盘和触屏操作。

迁移覆盖登录与 OAuth 回调、初始化、图库、上传、相册、回收站、密钥、账户、运行概览、用户、分组、存储及设置。上传任务跨页面保留，取消编辑不提交，批量操作逐项报告结果，权限由服务器再次校验。

## 认证

统一登录使用 `https://oauth.five-plus-one.com/oidc`，生产回调为 `https://img.five-plus-one.com/auth/callback`，初始化回调为 `https://img.five-plus-one.com/setup/auth/callback`。以浏览器实际应用类型核对客户端认证要求；凭据保存在受限运行配置。保留本地管理员作为恢复入口。

现有应用为传统网页应用。后端通过受限环境变量 `OIDC_CLIENT_SECRET` 完成客户端认证，使用经签名、发行者和客户端受众校验的 ID Token 建立 HttpOnly 会话；访问令牌不作为必须为 JWT 的身份依据。客户端 secret 仅对环境中同一 OIDC_CLIENT_ID 生效，避免后台切换应用时错用凭据。生产回调只允许本站登录与初始化路径。

## 上线与验收

现有域名转发到雨云应用机 Lsky。先构建独立候选，核对磁盘预算、数据库、数据卷和 OAuth 回调；旧数据迁移范围与切换时间由用户确认。旧资源地址和恢复材料保留，公网入口切换前备份代理配置。

用户已授权完成接入后随时切换并下线 Lsky，保持其他业务。旧图库包含 1 位用户、23 张 OSS 图片，图片集合为私有；导入后仅所属账户及授权管理员可管理，沿用原有公开图片链接，不创建全站公开图库。导入工具先验证原图内容与校验值，使用数据库事务写入图片记录和加密策略，默认只预检，显式 apply 才写入。原数据库、上传资源和容器配置作为恢复材料保留。

验收覆盖构建、类型、后端测试、真实上传与回收、账户隔离、OAuth 授权及回调会话、桌面/手机/分屏/连续缩放、深浅主题、提示与弹层、失败重试。上线后从公网复验图片、缩略图、API 和登录，不以健康检查代替业务验证。

旧图库缩略图：原文件与外链保留，迁移后按原图摘要校验读取，生成最长边 480 像素预览并存入同一存储策略的独立 islet-thumbs 路径；预览记录写入后由图库使用。

统计验收：上传趋势按数据库日期格式化为 YYYY-MM-DD 后汇总，确保当天上传计入对应日期；概览卡片依容器宽度排列。
